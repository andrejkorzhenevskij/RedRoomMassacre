# Red Room Massacre

An experimental Unity/C# game prototype focused on
physical close-quarters combat and camera-based gameplay.

## Features

- Character stances, movement, and collision handling.
- Physical interactions, grappling, and combat.
- Damage and injury systems.
- Handheld and placed cameras.
- Round lifecycle and gameplay state management.

## Technical Documentation

Detailed implementation notes, verification records,
and known limitations are available in
[Assets/RRM/README.md](Assets/RRM/README.md).

## Status

Technical prototype under development.
Not a released game.
